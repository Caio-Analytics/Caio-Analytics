# Caio Leão

### Data Analyst & Analytics Engineer

`loose spreadsheet → process the team can actually use`

🇧🇷 [Ler em português](README.md)

I have a very specific pet peeve: processes that depend on someone remembering the right order of spreadsheets and buttons. I have experience working with data in HR, Learning and Contracts. Today my focus is designing the architecture and organization of the lists that power Power Apps applications and automations. I like to find the bottleneck before automating anything.

I once took a manual three-day process and rebuilt it in Python so it generates the data in about a minute. Beyond being faster, the process has to show where a number came from when someone asks, and help catch errors before they turn into a dashboard.

My public projects are where I test ideas more calmly. I use Medallion Architecture (bronze, silver and gold layers, from raw data to analysis-ready), document lineage and leave tests along the way, because data without context and verification means double the work later.

## Where to start

- **[Estrato](https://github.com/Caio-Analytics/Estrato-Panorama-Mineral-Brasileiro)**: pipeline on public data from Brazil's mining agency (ANM), 10,295 records from 2010 to 2025, built with Polars, dbt and DuckDB and covered by 57 data tests. Has a [live dashboard](https://caio-analytics.github.io/Estrato-Panorama-Mineral-Brasileiro/) and [dbt lineage](https://caio-analytics.github.io/Estrato-Panorama-Mineral-Brasileiro/dbt/). (In Portuguese.)
- **[Recon](https://github.com/Caio-Analytics/Recon)**: look at a dataset before you trust it. Local data profiling and quality checks, with personal-data detection (Brazil's LGPD), CPF/CNPJ validation and an HTML report.
- **[colsemantics](https://github.com/Caio-Analytics/colsemantics)**: figure out what a mysterious corporate column means (role, domain and sensitivity). Available on [PyPI](https://pypi.org/project/colsemantics/).

The rest is in my pinned repositories and in the [portfolio](https://caio-analytics.github.io/Portfolio-Caio-Leao/), with more context, code and screenshots.
