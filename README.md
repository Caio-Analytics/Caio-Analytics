# Caio Leão

## Analista de Dados e Analytics Engineer

Trabalho com dados de RH na Vale Base Metals, Planta Salobo. Estruturo dados para análise, construo dashboards em Power BI e automatizo rotinas que consumiam tempo da equipe. Nos projetos públicos, aprofundo qualidade, modelagem e engenharia de dados com código, testes e documentação que podem ser conferidos.

[Portfólio](https://caio-analytics.github.io/Portfolio-Caio-Leao/) · [LinkedIn](https://www.linkedin.com/in/caio-le) · [E-mail](mailto:caiolmnnml@proton.me)

## Resultados do trabalho

- Mais de 14 dashboards em Power BI sustentados.
- Mais de 300 usuários ativos no aplicativo que reúne os dashboards.
- Um processo manual de três dias passou a ter uma versão em Python que gera os dados em aproximadamente um minuto.
- Outra rotina de duas a três horas de trabalho manual foi substituída por um dashboard atualizado diariamente.
