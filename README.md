Não confio em dado que não passou por teste. Trabalho com dados de RH na Vale Base Metals, Planta Salobo, e gosto de transformar rotina manual em algo que a equipe consiga consultar, manter e conferir. Nos projetos públicos, uso Arquitetura Medallion, documento a linhagem e só acredito no número depois que ele sobrevive a um `assert`.

Já transformei um processo manual de três dias em uma rotina de Python que gera os dados em aproximadamente um minuto. O resto está nos repositórios e no portfólio, com código, print e contexto para quem quiser fuçar.

- 🔭 Atualmente: Analista de Dados na **Vale Base Metals**
